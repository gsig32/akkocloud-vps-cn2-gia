## 500Mbps 带宽和 500GB 流量，哪个才是限制

很多人看到「500Mbps 带宽」就以为可以随便跑，实际卡住你的是月流量。按 500Mbps 的峰值速度跑，500GB 流量大约 2.3 小时就耗完了。带宽是瞬时上限，流量才是每月配额，这两个数要分开看。

500GB/月摊到每天约 16.7GB。一个页面含图片按 1.5MB 估算，一天大约能承接 1.1 万次页面浏览。产品图多、图片没压缩过的站，实际能撑的访问量会低不少。做投放的外贸站，一次广告爆量就可能把这个额度吃掉。

10G 硬盘是另一个容易忽略的硬限制。WordPress 本体加插件就占掉 1G 左右，剩下 9G 存产品图，几百张高清图就满了。要么上传前压图，要么把图片放对象存储，要么直接选 20G 的 B1。这一点比 CPU 和内存更早成为瓶颈。

## CN2 GIA 贵在哪，AkkoCloud 是不是全系都是

CN2 GIA 是中国电信的商用直连线路，回程不绕公网拥堵节点。普通国际线路在晚高峰丢包、延迟飙到 300ms 的情况并不少见，CN2 GIA 在同样时段通常能维持在稳定水平。外贸站真正被这条线路救回来的场景，是国内团队每天登后台改价格、传图、看订单的时候。

市面上卖 VPS 的商家通常按线路分三档：

- **三网优化档**（CN2 GIA + 联通 9929 + 移动 CMI）：国内外都顺，价格最高
- **折中档**（移动 CMIN2 或 CN2 去程 + 普通回程）：比顶级档便宜，晚高峰偶尔抖
- **国际线路档**（纯 Tier 1，无中国优化）：最便宜，海外访客够用，国内管理后台会难受

AkkoCloud 的产品线把这三档的差异简化了：所有 VPS 套餐都标 CN2 GIA，没有单独的「廉价国际线路」产品。省了你比线路的功夫，代价是最便宜那档也不便宜。第三方测评提到它的三网回程都走 GIA，这一点我没法自己验证，下单前可以开工单问一句「移动和联通回程是否也是 GIA」，答复会写得很清楚。

同线路类型的其他商家，1核1G 配置月付普遍在百元上下。AkkoCloud 把年付压到 ¥299，这是它在外贸圈被提起的主要原因。

## 下单前确认这几件事

1. **付款方式**：确认支付宝可用，以及是否支持你手上的其他渠道。
2. **退款条款**：官网首页只写了工单响应承诺（工作时间内 24 小时答复、48 小时解决），没有公示具体退款期限。下单前开工单问清楚「几天内可退、退到余额还是原路、是否扣手续费」。
3. **续费价**：年付套餐第二年是否同价，直接问。
4. **流量超额怎么算**：是限速、停机，还是按 GB 加钱，三种处理方式对业务影响完全不同。
5. **IP 能否更换、是否收费**：站被牵连封 IP 时这条很关键。
6. **系统模板与登录方式**：确认有你需要的系统版本，以及是否支持密码登录（有些商家默认只给 SSH Key）。

客服在线时间是中午十二点到晚上十点，急事走工单，别指望半夜有人回。
